# welkedresscode.nl

Website die uitlegt wat een dresscode betekent (Nederlands en Engels), met illustraties voor man en vrouw.

- `src/app.html` – bron van de site (data, illustraties en app)
- `tools/build.mjs` – bouwt de statische site in `site/` (pagina per dresscode, sitemap, enz.)
- `tools/og.py` – maakt de deelplaatjes in `site/og/`
- `site/` – wordt door Netlify gepubliceerd
